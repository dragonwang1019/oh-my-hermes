# 算數小島大冒險（國小二年級數學）

單一 HTML 檔，直接用瀏覽器開啟 `index.html` 即可遊玩，不需安裝。

- **闖關冒險**：10 座小島、3 顆愛心、星星評分、逐關解鎖
- **模擬考卷**：20 題 × 5 分，交卷打分數＋錯題訂正；可選擇年級、是否考九九乘法；輸入同一「考卷編號」可重現同一份考卷
- **單元練習**：15 個單元無限出題、連擊獎勵
- **60 秒快算**：加減與九九乘法速算，記錄最佳成績
- **出題設定**：首頁可開關「出題包含九九乘法」，套用到所有模式（關閉時跳過乘法關卡、隱藏乘法單元、快算只出加減）
- **離開鍵**：作答中左上角「✕ 離開」，離開前會先確認
- **貼紙簿**：金幣抽動物貼紙（存在瀏覽器 localStorage）

題庫為「程式隨機生成＋固定概念題」，涵蓋：數到 1000、加減直式（進退位）、填□、九九乘法、看圖列式、加減／乘法應用題、長度、時間（時鐘 SVG）、錢幣、分數、圖形、日曆、找規律。

## 考卷編號

格式：`[G年級-]數字[N]`，編號本身記住所有出題設定。

| 編號 | 意思 |
|---|---|
| `2468` | 二年級、含九九乘法 |
| `2468N` | 二年級、不含九九乘法（乘法題改由加減、數字、填□、應用題補足） |
| `G3-2468` | 三年級（預留，新增題庫後可用） |

## 新增年級

1. 在 `T` 新增該年級的單元產生器。
2. 在 `GRADES` 加一筆：`name`、`exam(o)`（回傳 20 個單元代號，`o.mul` 為是否考乘法）、`range(o)`（範圍說明）。
3. 年級選單與考卷編號會自動支援新年級。
