# 算數小島大冒險（國小二年級數學）

單一 HTML 檔，直接用瀏覽器開啟 `index.html` 即可遊玩，不需安裝。

- **闖關冒險**：10 座小島、3 顆愛心、星星評分、逐關解鎖
- **模擬考卷**：20 題 × 5 分，交卷打分數＋錯題訂正；輸入同一「考卷編號」可重現同一份考卷
- **單元練習**：15 個單元無限出題、連擊獎勵
- **60 秒快算**：加減與九九乘法速算，記錄最佳成績
- **貼紙簿**：金幣抽動物貼紙（存在瀏覽器 localStorage）

題庫為「程式隨機生成＋固定概念題」，涵蓋：數到 1000、加減直式（進退位）、填□、九九乘法、看圖列式、加減／乘法應用題、長度、時間（時鐘 SVG）、錢幣、分數、圖形、日曆、找規律。
